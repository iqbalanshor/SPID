## Sistem Pengaduan Infrastruktur Daerah ##

## Tampilan User Interface ( UI ) ##

### Halaman Register
Halaman ini digunakan oleh pengguna baru untuk membuat akun sebelum bisa menggunakan layanan SPID. Pengguna mengisi data diri seperti nama, email, nomor HP, username, dan password, lalu menyetujui syarat & ketentuan yang berlaku sebelum menekan tombol pendaftaran.

### Halaman Login User dan Admin
Halaman ini menjadi pintu masuk bagi pengguna dan admin yang sudah memiliki akun. Pengguna dan admin cukup memasukkan email dan kata sandi, kemudian melewati verifikasi captcha untuk memastikan yang login bukan bot, sebelum akhirnya diarahkan ke dashboard.

### Halaman Dashboard User
Halaman ini menjadi tampilan utama setelah login berhasil. Di sini pengguna disambut dengan informasi umum mengenai tujuan dan manfaat platform SPID sebagai jembatan komunikasi antara masyarakat dan dinas terkait, lengkap dengan prinsip layanan yang dijunjung serta pengumuman terbaru seputar kegiatan infrastruktur di daerah.

<img width="1899" height="1080" alt="Screenshot (31)" src="https://github.com/user-attachments/assets/66ca6393-a324-46ba-b563-de902db5a908" />

### Halaman Form Pengaduan User
Halaman ini digunakan pengguna untuk melaporkan kerusakan infrastruktur yang mereka temui, mulai dari memilih jenis kerusakan, menuliskan lokasi kejadian secara rinci, menjelaskan kondisi kerusakan, hingga melampirkan foto sebagai bukti pendukung agar laporan dapat segera diverifikasi dan ditindaklanjuti petugas.

<img width="1899" height="1080" alt="Screenshot (32)" src="https://github.com/user-attachments/assets/945873f0-a52c-4e7b-a2f8-43e5b6a74f0e" />

### Halaman Tracking Pengaduan User
Halaman ini menampilkan seluruh riwayat laporan yang pernah dikirim pengguna dalam bentuk daftar, sehingga pengguna dapat dengan mudah memantau status terkini dari setiap laporannya, apakah masih diproses atau sudah selesai ditangani.

<img width="1920" height="1080" alt="Screenshot (33)" src="https://github.com/user-attachments/assets/2c62aff6-dcee-43ae-ae86-4171a163f8fd" />

### Halaman Detail Pengaduan User
Halaman ini menampilkan informasi menyeluruh dari satu laporan tertentu, mulai dari data laporan dan foto bukti kerusakan, hingga timeline penanganan yang menunjukkan perjalanan laporan tersebut secara bertahap mulai dari diterima, diverifikasi, dikerjakan, hingga dinyatakan selesai sehingga prosesnya terasa transparan bagi pelapor.

### Halaman Kelola Profil User dan Admin
Halaman ini digunakan pengguna dan admin untuk melihat dan memperbarui data pribadinya, seperti nama, email, nomor WhatsApp, dan foto profil, agar informasi yang tersimpan di sistem selalu akurat dan memudahkan proses koordinasi terkait laporan yang diajukan.

### Halaman Dashboard Admin
Halaman ini menjadi tampilan utama bagi admin setelah login, menyajikan ringkasan performa pengelolaan infrastruktur secara cepat. Admin dapat melihat total laporan, jumlah yang sedang diproses, laporan selesai, hingga laporan yang butuh perhatian khusus, dilengkapi grafik tren pengaduan bulanan dan kategori kerusakan yang paling sering dilaporkan warga.

<img width="1893" height="1080" alt="Screenshot (36)" src="https://github.com/user-attachments/assets/095d15c8-58d1-48cc-bd54-68a21b4a0bd2" />

### Halaman Data Pengaduan Admin
Halaman ini menjadi pusat manajemen seluruh laporan yang masuk dari warga. Admin dapat melihat daftar lengkap laporan beserta status penanganannya, memfilter berdasarkan jenis infrastruktur (Jalan, Jembatan, Irigasi, Dll), serta melakukan aksi lanjutan seperti melihat detail atau menghapus laporan yang tidak relevan.

<img width="1920" height="1080" alt="Screenshot (37)" src="https://github.com/user-attachments/assets/d9566c20-cfa8-4ab3-b55d-dfb7c0b38ad2" />

### Halaman Detail Pengaduan Admin
Halaman ini menampilkan informasi lengkap dari satu laporan yang dipilih, mulai dari data pelapor, deskripsi kerusakan, kategori, urgensi, hingga foto bukti kerusakan. Admin juga dapat langsung mengambil tindakan cepat seperti memperbarui status, menolak laporan, atau menghapusnya, sambil memantau timeline penanganan laporan tersebut secara berurutan.

<img width="1896" height="1080" alt="Screenshot (38)" src="https://github.com/user-attachments/assets/991e28c2-6c33-4a87-9b8e-99ab20637e0f" />

### Halaman Export Laporan Admin
Halaman ini memudahkan admin untuk menyaring dan mengunduh data pengaduan berdasarkan rentang tanggal, kategori infrastruktur, maupun status penanganan. Hasil saringan dapat langsung dipratinjau dalam bentuk tabel sebelum dicetak atau diunduh sebagai laporan resmi, lengkap dengan indikator rasio penyelesaian laporan.

<img width="1893" height="1080" alt="Screenshot (39)" src="https://github.com/user-attachments/assets/9c744dfd-63fc-4370-a4d1-5a61aa45c325" />

### Halaman Manajemen Admin
Halaman ini digunakan untuk mengelola akun-akun yang terdaftar dalam sistem, baik admin maupun warga. Admin dapat menambahkan akun administrator baru, melihat daftar seluruh pengguna beserta perannya, serta memantau sesi login yang sedang aktif di sistem untuk menjaga keamanan akses.
